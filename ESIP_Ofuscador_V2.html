Ofuscador Autônomo V2

Processamento local: o HTML é preparado neste navegador. Não há envio para servidores, Firebase, cadastro ou biblioteca externa. O resultado é um arquivo HTML independente para publicar no GitHub Pages.
Limite de segurança: esta ferramenta dificulta a leitura casual usando fragmentação, codificação e identificadores aleatórios. Não é criptografia forte: como o navegador precisa reconstruir a página, alguém determinado ainda pode recuperar o conteúdo. Não coloque senhas, chaves privadas ou segredos no HTML.

Dica: guarde sempre uma cópia do HTML original. Teste o arquivo gerado localmente antes de substituir o index.html publicado.
